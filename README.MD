## Building

Requires CMake 3.25+ and a compiler with C++23 and `#embed`, which means
GCC 15 or newer, or Clang 19 or newer (clang-cl included). Everything is
driven from `CMakePresets.json`:
```
cmake --preset linux-gcc        && cmake --build --preset linux-gcc
cmake --preset linux-clang      && cmake --build --preset linux-clang
cmake --preset windows-clang-cl && cmake --build --preset windows-clang-cl
```
